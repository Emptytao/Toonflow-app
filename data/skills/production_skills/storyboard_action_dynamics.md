# 详细动态描述

## 使用边界

- 只服务分镜表阶段。
- 只负责动作链表达和动态可拍性。
- 不写光影、配乐、最终视频风格化措辞。

## 动作链写法

- 动作优先写成“起手 → 过程 → 落点”的连续链。
- 能看到动作如何发生，就不要只写终态。
- 常见动作链模板：
  - 视线先锁定 → 身体启动 → 手部动作兑现
  - 蓄力 → 发力 → 碰撞 → 结果
  - 停顿 → 试探 → 接近 → 触碰 / 回避

## 节拍控制

- 单镜动作数量要与时长匹配。
- 一个镜头内优先只保留 1 个主动作链，其他动作只能做陪衬。
- 如果一个动作包含明显阶段变化，应考虑拆成两镜：
  - 预备 / 对峙
  - 兑现 / 结果

## 多角色动作

- 多角色镜头按主次关系写动作，不要所有人同时抢节奏。
- 主体先写，回应者后写。
- 配角动作只服务主情绪或主冲突，不单独抢戏。

## 连续性

- 下一镜必须承接上一镜的动作终态。
- 上一镜若停在“手已抬起”，下一镜不能回到“手刚抬”。
- 有走位变化时，动作、朝向、空间关系要同步更新。

## 动作风险提示

- 如果一个镜头里同时要求大幅走位、多人反应、长台词和复杂物理动作，优先拆镜。
- 若一个动作的过程比结果更有戏，应把过程留在镜头里，而不是只拍结果。
